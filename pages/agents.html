oa-practice Turn a coding-assessment problem into a local OA workspace with Run / Submit scoring. 把笔试/机考题变成带 Run / Submit 评分的本地 OA 练习场。

Harness-oriented评测 harness 导向 Hidden judge隐藏判题器 Complexity profiling复杂度剖析 Score-gated practice按分练习

Paste a problem statement; the skill scaffolds a workspace with samples wired to a runner and a hidden judge over generated tests. It leaves solve() as a TODO unless you ask otherwise. Use when you want OA practice with a real score, not a solved algorithm handed to you. 粘贴题面后，技能会搭好带样例运行与隐藏评测的工作区，默认不写算法（solve() 留 TODO）。适合想练 OA、看真实分数，而不是直接拿答案的场景。

code-winnow Strip AI-generated chaff from a diff before you commit. 提交前从 diff 里剔除 AI 生成的冗余代码。

Multi-agent review多智能体评审 Context management上下文管理 Diff-scoped限定 Diff 范围 Parallel judgment并行判定 Apply-on-approval批准后应用

Reviews only lines the current change added or modified — restated comments, unused bindings, mock-only tests, speculative abstraction, docs the change made false. Not a general code review or security audit. Say “winnow this” before opening a PR on agent-written code. 只审当前改动触及的行：重复注释、无用绑定、只测 mock 的测试、过度抽象、被改动证伪的文档。不是通用 code review 或安全审计。在 agent 写的代码开 PR 前说 “winnow this” 即可。

agent-delegation Run jobs you already decomposed across multiple provider seats, each in its own worktree. 把已拆分好的任务分发到多个提供方席位并行执行，每个任务一个独立 worktree。

Multi-provider routing多提供方路由 Quota-aware failover配额感知故障转移 Isolated worktrees隔离 worktree Scope + cost per job按任务记录范围与开销 Wrapper, not workflow只调度，不做工作流

A CLI wrapper with no planner and no reviewer: your agent writes the jobs, delegate sends each to a seat that still has quota, runs it in an isolated git worktree, and moves work when one provider hits a wall. Only worth it with more than one provider enrolled — delegate init prints the tier-to-seat table and says so outright. Nothing reviews the result; you get the files each job touched, what the checks said, and what each seat cost. 一个命令行封装：没有规划器，也没有评审器。任务由你的 agent 拆好，delegate 把每个任务分给仍有配额的席位，在隔离的 git worktree 中执行，某个提供方撞上配额墙时自动转移。只有接入多个提供方才值得用——delegate init 会打印 tier 与席位的对应表并直接给出结论。它不评审结果，只告诉你每个任务改了哪些文件、检查输出如何、各席位花了多少。

Two halves: clone the repo for the delegate CLI (Python 3.9+, stdlib only), then copy agent-delegation/ into your agent's skills directory — the skill alone does nothing. 分两部分：克隆仓库得到 delegate CLI（Python 3.9+，仅标准库），再把 agent-delegation/ 复制到 agent 的 skills 目录——只装技能本身不起作用。

oa-practice Turn a coding-assessment problem into a local OA workspace with Run / Submit scoring. 把笔试或机考题变成支持 Run／Submit 评分的本地 OA 练习环境。

Harness-oriented围绕评测框架 Hidden judge隐藏判题器 Complexity profiling复杂度剖析 Score-gated practice按分练习

Paste a problem statement; the skill scaffolds a workspace with samples wired to a runner and a hidden judge over generated tests. It leaves solve() as a TODO unless you ask otherwise. Use when you want OA practice with a real score, not a solved algorithm handed to you. 粘贴题面后，技能会搭好包含样例运行器和隐藏评测的工作区，默认把 solve() 留作 TODO，不直接替你写算法。适合想自己练习 OA、获得真实评分的场景。

code-winnow Strip AI-generated chaff from a diff before you commit. 提交前从 diff 里剔除 AI 生成的冗余代码。

Multi-agent review多智能体评审 Context management上下文管理 Diff-scoped限定 Diff 范围 Parallel judgment并行判定 Apply-on-approval批准后应用

Reviews only lines the current change added or modified — restated comments, unused bindings, mock-only tests, speculative abstraction, docs the change made false. Not a general code review or security audit. Say “winnow this” before opening a PR on agent-written code. 只检查当前改动触及的行，找出重复注释、无用绑定、只验证 mock 的测试、过度抽象，以及已被改动内容推翻的文档。它不是通用代码审查或安全审计；在 Agent 生成的代码准备开 PR 前说一句 “winnow this” 即可。

agent-delegation Run jobs you already decomposed across multiple provider seats, each in its own worktree. 把已经拆分好的任务分发给多个模型服务席位并行执行，每项任务使用独立的 worktree。

Multi-provider routing多提供方路由 Quota-aware failover配额感知故障转移 Isolated worktrees隔离 worktree Scope + cost per job按任务记录范围与开销 Wrapper, not workflow只负责调度

A CLI wrapper with no planner and no reviewer: your agent writes the jobs, delegate sends each to a seat that still has quota, runs it in an isolated git worktree, and moves work when one provider hits a wall. Only worth it with more than one provider enrolled — delegate init prints the tier-to-seat table and says so outright. Nothing reviews the result; you get the files each job touched, what the checks said, and what each seat cost. 这是一个不含规划器或评审器的命令行封装。任务由你的 Agent 预先拆分，delegate 再把每项任务分给仍有可用配额的席位，并在隔离的 Git worktree 中执行；某个服务商额度耗尽时，任务会自动转移。它只有在接入多个服务商时才有价值，delegate init 会列出层级与席位的对应关系并明确提示是否值得启用。工具不会评审结果，只会报告每项任务修改了哪些文件、检查结果如何，以及各席位的开销。

Two halves: clone the repo for the delegate CLI (Python 3.9+, stdlib only), then copy agent-delegation/ into your agent's skills directory — the skill alone does nothing. 安装分为两部分：先克隆仓库获取 delegate CLI（Python 3.9+，仅使用标准库），再把 agent-delegation/ 复制到 Agent 的 skills 目录；只安装技能本身无法运行。
